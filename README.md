# Event Organizer

Event Organizer is a web application that helps users plan and manage events in one place. Users can create an account, log in securely, create new events, view existing events, manage their profile, and send messages through the contact form.

## Features

- Secure user authentication
- Create and manage events
- View all events
- User profile
- Contact form

## Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- PostgreSQL
- Prisma ORM

**Authentication**
- JWT
- bcrypt

## Installation

Clone the repository.

```bash
git clone https://github.com/your-username/event-organizer.git
```

Install backend dependencies.

```bash
cd backend
npm install
```

Create a `.env` file and add the required environment variables.

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

Run the backend server.

```bash
npm run dev
```

Open the frontend using a local server such as Live Server.
